# Atolagbe Academy - Global Command Center 🚀

Welcome to the backend repository for the Atolagbe Academy digital platform. 

## Overview
This is a custom-built, Python-powered web engine designed to manage enterprise-level student access, host premium educational content (PDFs/Ebooks), and run interactive multiple-choice Q&A modules.

## Tech Stack
* Language: Python
* Framework: Flask
* Database: SQLite / SQLAlchemy
* Hosting Pipeline: GitHub to Render (Continuous Deployment)

## Current Version: V2
* Secure Master Admin Login
* Dynamic Ebook File Routing & Downloading
* Integrated Multiple-Choice Quiz Engine
